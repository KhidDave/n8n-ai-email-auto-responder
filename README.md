# AI Email Auto-Responder with n8n

## Overview
This project automates email responses using n8n and Google Gemini AI. When a new email arrives in Gmail, the workflow reads the email, generates a professional reply using AI, and sends the response automatically.

## Workflow

Gmail Trigger → AI Agent (Google Gemini) → Gmail Send

## Features

- Monitors incoming Gmail messages
- Generates AI-powered email replies
- Sends professional responses automatically
- Reduces manual email handling

## Technologies Used

- n8n
- Gmail
- Google Gemini AI

## How to Use

1. Import the workflow JSON into n8n.
2. Connect your Gmail account.
3. Connect your Google Gemini API credentials.
4. Activate the workflow.
5. Send a test email to verify the automation.
